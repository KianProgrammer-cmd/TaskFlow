# 🚀 TaskFlow

یک برنامه مدرن و ریسپانسیو برای مدیریت کارها، ساخته‌شده با HTML، CSS و JavaScript خالص.

## ✨ امکانات

- افزودن، حذف و ویرایش کارها
- علامت‌گذاری کارهای انجام‌شده
- فیلتر کارها
- جست‌وجوی سریع
- اولویت‌بندی کارها
- حالت تاریک و روشن
- ذخیره اطلاعات در LocalStorage
- نمایش آمار و درصد پیشرفت
- طراحی Responsive
- بدون نیاز به Backend

## 🛠️ اجرا

فایل `index.html` را در مرورگر باز کنید.

برای تجربه بهتر در VS Code می‌توانید از Live Server استفاده کنید.

## 🌐 انتشار در GitHub Pages

1. پروژه را در یک Repository جدید GitHub قرار دهید.
2. وارد بخش **Settings → Pages** شوید.
3. در قسمت Source گزینه **Deploy from a branch** را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/root` قرار دهید.
5. ذخیره کنید.

بعد از چند لحظه سایت شما با GitHub Pages در دسترس خواهد بود.
