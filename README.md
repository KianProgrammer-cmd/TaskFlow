# 🚀 TaskFlow

> یک اپلیکیشن مدرن و ساده برای مدیریت کارهای روزانه با HTML، CSS و JavaScript خالص.

## ✨ امکانات

* ➕ افزودن کار جدید
* ✏️ ویرایش کارها
* 🗑️ حذف کارها
* ✅ علامت‌گذاری کارهای انجام‌شده
* 🔍 جست‌وجوی سریع
* 🏷️ تعیین اولویت کارها
* 📊 نمایش تعداد کارها و درصد پیشرفت
* 🌙 حالت تاریک و ☀️ حالت روشن
* 💾 ذخیره خودکار اطلاعات با `LocalStorage`
* 📱 طراحی کاملاً Responsive
* ⚡ بدون نیاز به Backend یا دیتابیس

## 🛠️ تکنولوژی‌ها

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Responsive Design

## ▶️ اجرای پروژه

برای اجرای پروژه کافی است فایل زیر را با مرورگر باز کنید:

```text
todo-list/index.html
```

یا در VS Code با افزونه **Live Server** اجرا کنید.

## 🎨 طراحی

TaskFlow با تمرکز روی یک رابط کاربری مدرن، ساده و زیبا طراحی شده است.

ویژگی‌های ظاهری:

* Glassmorphism
* Gradient UI
* Dark/Light Mode
* انیمیشن‌های نرم
* طراحی مناسب موبایل و دسکتاپ

## 💾 ذخیره اطلاعات

اطلاعات کارها در `LocalStorage` مرورگر ذخیره می‌شوند؛ بنابراین با Refresh کردن صفحه، کارهای شما باقی می‌مانند.

> توجه: اطلاعات در مرورگر همان دستگاه ذخیره می‌شوند و بین دستگاه‌های مختلف همگام‌سازی نمی‌شوند.
